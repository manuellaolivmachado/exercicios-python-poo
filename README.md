# 🐍 Exercícios de Python - POO

Exercícios desenvolvidos em Python para praticar conceitos de Programação Orientada a Objetos (POO).

## 💻 Tecnologia

- Python

## 📚 Exercícios

### Exercício 1 - Aluno e Disciplina

Criação de classes para representar um aluno e uma disciplina, permitindo que o aluno se inscreva em uma disciplina.

**Conceitos praticados:**
- Classes
- Objetos
- Métodos
- Atributos
- Construtor `__init__`

### Exercício 2 - Departamento e Empregados

Criação de um departamento que permite adicionar e listar empregados.

**Conceitos praticados:**
- Classes e objetos
- Listas
- Métodos
- Estruturas de repetição
- Associação entre objetos

### Exercício 3 - Casa e Portas

Simulação de uma casa com três portas, permitindo alterar o estado de cada porta entre aberta e fechada.

**Conceitos praticados:**
- Classes
- Objetos
- Métodos
- Atributos
- Estruturas condicionais
- Estrutura de repetição `while`
- Composição entre objetos

### Exercício 4 - Veículos

Criação de uma classe `Veiculo` e duas classes derivadas, `Carro` e `Bicicleta`, que possuem diferentes comportamentos para o método `mover()`.

**Conceitos praticados:**
- Herança
- Polimorfismo
- Sobrescrita de métodos
- Classes e objetos

## 🎯 Objetivo

Estes exercícios foram desenvolvidos durante meus estudos de Python com o objetivo de praticar Programação Orientada a Objetos e desenvolver minha lógica de programação.

## 🚀 Aprendizados

Com esses exercícios, pratiquei a criação e utilização de classes, objetos, atributos e métodos, além de conceitos como herança, polimorfismo e composição.
